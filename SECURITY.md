# Reportar un problema de seguridad

Si el repositorio ofrece la opción **Report a vulnerability** en la sección Security, envía el informe por esa vía. Si la opción no está disponible, pide al mantenedor un canal privado antes de compartir los detalles. Evita incluir datos sensibles, credenciales o archivos de personas reales.

Incluye el alcance, la revisión de Git afectada, las condiciones necesarias, el resultado observado y una comprobación que pueda repetirse con datos ficticios. Borra cualquier credencial de las salidas y capturas antes de adjuntarlas.

Se revisará el reporte, se confirmará el impacto y se acordará una fecha de divulgación con la persona que lo informó. La corrección se validará en una rama de prueba antes de integrarse. Los detalles se publicarán una vez que exista una corrección o una medida de mitigación coordinada.
